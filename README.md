# 简单HTTP文件服务器

一个基于 Node.js 和 Express 的简单文件服务器，支持文件上传、下载和文件夹管理。

## 功能特点

- 📤 文件上传（支持多文件上传）
- 📥 文件下载
- 📁 创建文件夹
- 🗑️ 删除文件和文件夹
- 🔍 浏览文件系统
- 📱 响应式界面

## 安装

```bash
npm install
```

## 运行

```bash
npm start
```

服务器将在 http://localhost:3000 启动

## 开发模式

使用 nodemon 自动重启：

```bash
npm run dev
```

## 存储

所有上传的文件和创建的文件夹都存储在 `uploads/` 目录下。

## 注意事项

- 这是一个简单的文件服务器，没有用户认证系统
- 任何人都可以上传、下载和删除文件
- 请在受信任的网络环境中使用
