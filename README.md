# 简单HTTP文件服务器

一个基于 Node.js 和 Express 的简单文件服务器，支持文件上传、下载和文件夹管理，具有现代化的UI界面和完整的操作日志。

## 功能特点

- 📤 文件上传（支持多文件上传）
- 📥 文件下载
- 📁 创建和管理文件夹
- ✎ 重命名文件夹
- 🗑️ 删除文件和文件夹（带确认对话框）
- 🌲 树形目录结构（可展开/折叠、可调整宽度）
- 📋 操作日志（记录所有文件操作，按日期存储）
- 🎨 现代化渐变UI设计
- ℹ️ 内置使用帮助文档
- 📱 响应式界面

## 安装

```bash
npm install
```

## 配置

### 端口设置

在 `.env` 文件中配置端口（默认为 3000）：

```bash
PORT=4567
```

## 运行

```bash
npm start
```

服务器将在配置的端口启动（默认 http://localhost:3000）

## 开发模式

使用 nodemon 自动重启：

```bash
npm run dev
```

## 存储

- **上传文件**：所有上传的文件和创建的文件夹都存储在 `uploads/` 目录下
- **操作日志**：操作日志按日期存储在 `logs/` 目录下，格式为 `YYYY-MM-DD.log`

## 技术栈

- **后端**：Express 4.18.2, Multer 1.4.5, dotenv
- **前端**：原生 JavaScript + CSS3

## 注意事项

- 这是一个简单的文件服务器，没有用户认证系统
- 任何人都可以上传、下载和删除文件
- 请在受信任的网络环境中使用
- 删除操作不可恢复，请谨慎操作
