# 简单HTTP文件服务器

一个基于 Node.js 和 Express 的简单文件服务器，支持文件上传、下载、目录管理、回收站、搜索和空间信息查看，具有现代化 UI 界面和完整的操作日志。

## 功能特点

- 📤 文件上传（支持多文件上传）
- 🔁 上传冲突处理（替换 / 保留两者 / 跳过）
- 📥 文件下载
- 📁 创建和管理文件夹
- ✎ 重命名文件夹
- 📊 空间信息（目录占用、文件数量、磁盘可用空间）
- 🔎 文件/文件夹搜索（当前目录或全局，支持从结果直接进入目录）
- 🗑️ 删除文件和文件夹（带确认对话框）
- 🌲 树形目录结构（可展开/折叠、可调整宽度）
- 📋 操作日志（记录所有文件操作，按日期存储）
- 🎨 现代化渐变UI设计
- ℹ️ 内置使用帮助文档
- 📱 响应式界面

## 安装

```bash
npm install
```

## 配置

### 端口设置

在 `.env` 文件中配置端口（默认为 3000）：

```bash
PORT=4567
```

## 运行

```bash
npm start
```

服务器将在配置的端口启动（默认 http://localhost:3000）

## 开发模式

使用 nodemon 自动重启：

```bash
npm run dev
```

## 存储

- **上传文件**：所有上传的文件和创建的文件夹都存储在 `uploads/` 目录下
- **操作日志**：操作日志按日期存储在 `logs/` 目录下，格式为 `YYYY-MM-DD.log`
- **回收站**：删除的文件和文件夹会先进入 `trash/` 目录，可在页面中还原或彻底删除

## 交互说明

- **同名上传**：当目标目录已存在同名文件时，可选择替换、保留两者或跳过
- **普通删除**：文件和文件夹默认先进入回收站，可在回收站中恢复
- **搜索结果**：文件结果可点击路径进入所在目录，文件夹结果可点击路径直接进入该文件夹
- **彻底删除**：只有在回收站中执行“彻底删除”或“清空回收站”时才不可恢复

## 技术栈

- **后端**：Express 4.18.2, Multer 1.4.5, dotenv
- **前端**：原生 JavaScript + CSS3

## 注意事项

- 这是一个简单的文件服务器，没有用户认证系统
- 任何人都可以上传、下载和删除文件
- 请在受信任的网络环境中使用
- 删除操作默认进入回收站；从回收站彻底删除后不可恢复
